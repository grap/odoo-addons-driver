# Odoo Addons Module for Odoo Drivers

odoo-addons-driver is a repository that contains Odoo modules required when using the odoo-driver project.
(https://gitlab.com/odoo-driver/odoo-driver/#odoo-drivers)

This project is developped by GRAP company (www.grap.coop) and was originally hosted on the GitHub platform.
This project is now hosted on gitlab. (https://gitlab.com/odoo-driver/odoo-addons-driver).
